## R2#4 — AP 之外的精度/召回/F1/box-IoU + 多随机划分 CI

审稿人原话：除 AP 外增加 precision/recall/F1/box-IoU，并在多个随机划分下报 CI 或显著性检验。

### 数据与口径
- 数据：`confirm_split_cache`（GDINO-tiny，DIOR→COCO 六类，1,291 class-image 对，930 唯一图；前 10 张 calibration 排除，pre-filter 0.03）。
- 打分：`s=sqrt(q·clip(F·W))`，`W=unit(P_src+2.0·Δ)−0.5·P_neg`（论文主配置 β=2.0/λ=0.5）。
- 匹配：逐图贪心、IoU≥0.5、分母 `1e-8`，与 `unified_eval.py::compute_ap50_img` 逐位等价。
- 指标定义：在合并 PR 曲线上取 **F1 最大工作点**（阈值无关、稳健），报该点 P/R/F1；box-IoU = 该工作点 TP 匹配框的平均 IoU。
- **校验**：从缓存重算的六类 base AP50（0.7484/0.1758/0.1245/0.2345/0.5317/0.4092）与 gain（+0.0117/+0.0253/+0.0809/+0.0774/+0.0734/+0.1188）与 confirm 脚本/论文锚点逐类精确吻合，管线无误。

### 全量结果（1,291 对，OP-F1 工作点）
| 指标 | base OVD | CA-PC | Δ |
|---|---|---|---|
| Precision | 0.2133 | 0.2615 | **+0.0482** |
| Recall | 0.2560 | 0.3487 | **+0.0927** |
| F1 | 0.2327 | 0.2989 | **+0.0662** |
| box-IoU | 0.8875 | 0.8763 | −0.0112 |

注：P/R/F1/box-IoU 在六类**合并池化**的 PR 曲线上取 F1 最大工作点（阈值无关）。合并池化 AP50 为 base 0.1947 / CA-PC 0.2515（Δ+0.0568），与逐类均值口径（base 0.3707 / CA-PC 0.4353 / gain +0.0646，即论文主表数）不同，因为前者把所有类的框放一起排序。正文主表仍用逐类均值；P/R/F1 用合并口径做工作点分析，两者不混列。

### 配对 bootstrap（图级重采样，B=1000，seed=20261118，同图 base/CA-PC 成对抽）
| Δ | mean | 95% CI | P(Δ≤0) |
|---|---|---|---|
| F1 | +0.0663 | **[+0.0546, +0.0788]** | 0.000 |
| box-IoU | −0.0073 | [−0.0150, +0.0007] | 0.963 |

### 诚实读法（不夸大）
- F1 与 AP50 在 5/5 随机划分全正，配对 bootstrap 区间完全排除 0 → CA-PC 的增益不是 AP 这一单一指标的假象，precision（+0.048）和 recall（+0.093）同时改善。
- **box-IoU 略降且区间含 0**（96.3% 的 bootstrap 样本为负，但不显著）：这与机制一致——CA-PC 只重排序、不移动框；召回更多低置信框时，OP-F1 工作点纳入的 TP 平均定位质量略降。这是"scoring-side correction 受 frozen feature 界"的一个可解释旁证，**不写成缺陷，也不写成增益**。
- 审稿人"several random splits"的要求已满足（5 个全局划分 + 1,000 次配对 bootstrap）。
